Tarea 1 — Configurar credenciales secretas (EAS Secrets) URGENTE

¿Por qué hay que hacer esto?
Tu app necesita conectarse a Firebase (base de datos) y Cloudinary (fotos) usando unas "contraseñas" llamadas API Keys. Antes estaban escritas directamente en el código (lo cual era un riesgo de seguridad). Las movimos a un sistema seguro llamado EAS Secrets, que las guarda encriptadas en los servidores de Expo. Ahora tienes que "cargarlas" ahí.

Paso 1 — Abrir la terminal

1

En Windows, presiona Windows + R, escribe cmd y presiona Enter.

O abre Visual Studio Code, ve al menú superior → Terminal → New Terminal.

Paso 2 — Ir a la carpeta del proyecto

2

En la terminal, escribe exactamente este comando y presiona Enter:

cd "C:\Users\JOAQUIN\Desktop\SENERGY-17-10\SENERGY"

Verás que el "prompt" cambia y muestra la ruta de tu proyecto. Eso significa que estás en la carpeta correcta.

Paso 3 — Instalar EAS CLI (solo la primera vez)

3

Copia y pega este comando, luego presiona Enter:

npm install -g eas-cli

Espera a que termine (puede tomar 1-2 minutos). Verás mucho texto en la pantalla, eso es normal.

Paso 4 — Iniciar sesión en Expo

4

Escribe este comando y presiona Enter:

eas login

Te pedirá tu email y contraseña de expo.dev. Escríbelos y presiona Enter en cada uno.

Si no tienes cuenta, créala gratis en https://expo.dev antes de continuar.

Paso 5 — Cargar las credenciales una por una

Copia y pega cada comando abajo en la terminal. En cada uno te preguntará si quieres continuar — escribe Y y presiona Enter.

💡 Consejo: Puedes encontrar los valores reales de estas variables abriendo el archivo .env que está en la carpeta del proyecto. Ábrelo con el Bloc de Notas.

Credencial 1 — Firebase API Key:

eas secret:create --scope project --name FIREBASE_API_KEY --value "(ver .env)"

Credencial 2 — Firebase Auth Domain:

eas secret:create --scope project --name FIREBASE_AUTH_DOMAIN --value "senergy-46b1e.firebaseapp.com"

Credencial 3 — Firebase Project ID:

eas secret:create --scope project --name FIREBASE_PROJECT_ID --value "senergy-46b1e"

Credencial 4 — Firebase Storage Bucket:

eas secret:create --scope project --name FIREBASE_STORAGE_BUCKET --value "senergy-46b1e.firebasestorage.app"

Credencial 5 — Firebase Messaging Sender ID:

eas secret:create --scope project --name FIREBASE_MESSAGING_SENDER_ID --value "1004118309867"

Credencial 6 — Firebase App ID:

eas secret:create --scope project --name FIREBASE_APP_ID --value "1:1004118309867:web:6385b378eb0217b009b7ae"

Credencial 7 — Firebase Measurement ID:

eas secret:create --scope project --name FIREBASE_MEASUREMENT_ID --value "G-TRGG3EPHJ9"

Credencial 8 — Cloudinary Cloud Name:

eas secret:create --scope project --name CLOUDINARY_CLOUD_NAME --value "dinxnxpn4"

Credencial 9 — Cloudinary Upload Preset:

eas secret:create --scope project --name CLOUDINARY_UPLOAD_PRESET --value "senergy_unsigned"

Paso 6 — Verificar que se cargaron correctamente

6

Escribe este comando para ver la lista de secrets cargados:

eas secret:list

Deberías ver las 9 credenciales que acabas de cargar. Si aparecen todas, ¡esta tarea está completa!

✓ Tarea 1 completada. Las credenciales están seguras en los servidores de Expo y se inyectarán automáticamente en cada build de producción.

Tarea 2 — Crear tu App iOS en Google AdMob URGENTE

¿Por qué hay que hacer esto?
SENERGY muestra anuncios a los usuarios del plan gratuito. Para iOS (iPhone/iPad), Google AdMob requiere registrar tu app y te da un App ID único. Sin él, la app no pasará la revisión de Apple.

Nota: Si por ahora solo vas a lanzar en Android, puedes saltarte esta tarea y hacerla cuando estés listo para iOS.

Paso 1 — Ir a la consola de AdMob

1

Abre tu navegador y ve a: https://admob.google.com

Inicia sesión con la misma cuenta de Google que usaste para crear el proyecto de AdMob Android (ca-app-pub-4937459209805273).

Paso 2 — Agregar nueva app

2

En el menú de la izquierda, haz clic en "Aplicaciones".

Luego haz clic en el botón azul "Agregar aplicación".

Paso 3 — Configurar la app iOS

3

Selecciona la plataforma: iOS

Cuando te pregunte si la app está en el App Store, selecciona "No" (todavía no la hemos publicado).

Nombre de la app: escribe SENERGY

Haz clic en "Agregar app".

Paso 4 — Copiar el App ID

4

AdMob te mostrará un ID de aplicación con este formato:

ca-app-pub-4937459209805273~XXXXXXXXXX

Copia ese número completo (incluida la parte ca-app-pub-...).

Paso 5 — Guardarlo como EAS Secret

5

Abre la terminal (como en la Tarea 1) y ejecuta este comando, reemplazando PEGAR_TU_ID_AQUI con el ID que copiaste:

eas secret:create --scope project --name IOS_ADMOB_APP_ID --value "PEGAR_TU_ID_AQUI"
✓ Tarea 2 completada. Los builds de iOS ya usarán tu ID real de AdMob.

Tarea 3 — Implementar sistema de pagos real (RevenueCat) URGENTE

¿Por qué hay que hacer esto?
Actualmente, cuando alguien presiona "Activar Premium" en la app, simplemente se activa sin cobrarle nada. Para cobrar el plan de $1.000 CLP/mes de verdad, necesitas un sistema de pagos. La solución más simple para Expo es RevenueCat, que actúa como intermediario entre tu app y las tiendas (Apple / Google).

Esta tarea tiene dos partes:
   — Parte A: Tú configuras cuentas en sitios web (lo haces solo).
   — Parte B: Claude hace los cambios en el código (pídelo cuando termines la Parte A).

Parte A — Lo que haces tú

Paso 1 — Crear cuenta en RevenueCat

1

Ve a https://www.revenuecat.com y haz clic en "Get Started Free".

Regístrate con tu email. El plan gratuito incluye hasta $2.500 USD/mes de ingresos sin comisiones adicionales de RevenueCat (las tiendas siempre cobran 15-30%).

Paso 2 — Crear un proyecto en RevenueCat

2

Después de registrarte, haz clic en "Create new project".

Nombre: SENERGY

Luego agrega las dos plataformas:

  • Haz clic en "+ Add app" → selecciona Google Play Store

    - Package name: com.energysaver.senergy

  • Haz clic en "+ Add app" → selecciona App Store

    - Bundle ID: com.energysaver.senergy

Paso 3 — Copiar tu API Key de RevenueCat

3

Dentro de tu proyecto en RevenueCat, ve a Project Settings → API Keys.

Verás dos claves públicas (una para Android, una para iOS). Cópialas, las vas a necesitar.

Formato: appl_XXXXXXXXXXXXXXXX (iOS) y goog_XXXXXXXXXXXXXXXX (Android)

Paso 4 — Crear el producto en Google Play Console

4

Ve a https://play.google.com/console e ingresa con tu cuenta de Google Play Developer.

Selecciona tu app SENERGY → en el menú izquierdo busca "Monetización" → "Suscripciones".

Haz clic en "Crear suscripción" y configura:

  • ID del producto: senergy_premium_monthly

  • Nombre: SENERGY Premium

  • Período de facturación: Mensual

  • Precio: $1.090 CLP (Google cobra comisión, así el usuario ve ~$1.000)

Paso 5 — Crear el producto en App Store Connect (si tienes cuenta de Apple Developer)

5

Ve a https://appstoreconnect.apple.com e ingresa con tu Apple ID.

Selecciona tu app → "Monetización" → "Suscripciones".

Crea un grupo de suscripción llamado "Premium" y agrega:

  • Nombre de referencia: SENERGY Premium Mensual

  • ID del producto: com.energysaver.senergy.premium.monthly

  • Duración: 1 mes

  • Precio: elige la franja más cercana a $1.000 CLP (Apple usa franjas fijas)

Paso 6 — Conectar productos en RevenueCat

6

Vuelve a RevenueCat → Products → "+ New Product".

Agrega el ID que usaste en Google Play: senergy_premium_monthly

Repite para el ID de Apple si lo creaste.

Luego ve a Entitlements → "+ New Entitlement":

  • ID: premium

  • Asocia los productos que acabas de crear.

Parte B — Lo que hace Claude (cuando termines la Parte A)

Cuando hayas completado todos los pasos de la Parte A, dile a Claude:

"Tengo lista la cuenta de RevenueCat. Mi API Key de Android es [CLAVE] y la de iOS es [CLAVE]. Implementa el sistema de pagos en SENERGY."

Claude instalará el SDK de RevenueCat y actualizará PricingScreen.js para cobrar de verdad.

Tarea 4 — Preparar las cuentas de las tiendas ANTES DEL BUILD

Google Play Console

Necesitas una cuenta de Google Play Developer ($25 USD, pago único).

Crea la app en: https://play.google.com/console

Package name: com.energysaver.senergy

Descarga la Service Account Key para el submit automático:

  1. En Google Play Console → Configuración → Acceso API

  2. Vincula con Google Cloud → Crea cuenta de servicio

  3. Descarga el archivo JSON → Renómbralo a google-play-key.json

  4. Colócalo en la carpeta raíz del proyecto SENERGY

Apple App Store Connect (solo si vas a publicar en iOS)

Necesitas una cuenta de Apple Developer ($99 USD/año).

Crea la app en: https://appstoreconnect.apple.com

Bundle ID: com.energysaver.senergy
